# Brand image folders

Each client gets one folder under `assets/brands/`. Set `brand.assetsDir` in
`config.js` to point to that folder, then replace these standard filenames:

- `logo.png` — header, footer, favicon, and about mark
- `hero.jpg` — hero background
- `gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg` — gallery cards
- `staff-1.jpg`, `staff-2.jpg`, `staff-3.jpg` — team portraits (optional)

Missing gallery and staff files fall back to the existing placeholders. Custom
paths still work when a client needs a different filename.
